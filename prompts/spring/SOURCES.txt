SPRING reproduction sources and adaptations

Algorithm: Yue Wu et al., SPRING: Studying the Paper and Reasoning to Play Games
https://arxiv.org/abs/2305.15486

Question text and dependency graph:
https://github.com/Holmeswww/SPRING/blob/c0369b9127ab9ec63797797a3952be9e119334e1/GPT_Actor_Chat.ipynb
The nine questions and direct dependencies are preserved. Root questions were
implicit dependency leaves in the notebook; they are explicit q1 and q2 here.
The fixed topological traversal removes Python set iteration nondeterminism.
Each question receives only its direct parents' answers from the current step,
the paper knowledge, and the latest two observations. No answers persist across
steps. The first decision uses the reset observation instead of stepping noop.

Project adaptations:
- Local Ollama model replaces the paper's GPT-4.
- The shared project's local semantic grid and last action replace SmartPlay's text
  observation; no privileged world state is added. Recent observations remain a
  two-frame window. Coordinate and API action naming are explained in system.txt.
- The configured episode goal and optional success condition are explicit.
- q1 through q8 produce free text. qa requests a JSON object with an action from
  the environment's action list. Invalid output fails explicitly; the notebook's
  substring matcher and fallback Do action are not retained.
- Every node is a separate, budgeted model call. Environment steps occur only
  after all nine nodes complete; partial decisions never advance the game.
  If fewer than nine calls remain, the decision stops before calling the model.
These are method-level reproductions under this project's environment/model
protocol. Results must not be described as reproducing the original paper score.
